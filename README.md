


## 🔧 ما هو Execllent Server Manager؟

**Execllent Server Manager** هو بلوقن متكامل لإدارة سيرفرك في ماينكرافت بسهولة واحتراف.
يجمع بين أوامر إدارية قوية داخل اللعبة، وتكامل متقدم مع Discord، مما يجعله مثالي لسيرفرات السيرفايفل، البقاء، أو حتى المجتمعات الكبيرة.

---

### 🎮 مميزاته باختصار:

* أمر رئيسي موحّد يحتوي على أوامر مثل: **reload**, **tpall**, **tp** وغيرها
* تحكم كامل في السباون، التنقل، والرؤية الليلية
* نظام تحقيق مع اللاعبين المشبوهين (SS)
* ربط حساب Minecraft بـ Discord
* مزامنة رتب، حظر تلقائي، وتسجيل كل الأحداث
* إرسال تنبيهات للسيرفر في Discord
* نظام محادثة مشترك بين اللعبة وDiscord
* إيفنت بلوكات مؤقتة في عوالم معينة
* رسائل دخول/خروج مميزة مع Title
